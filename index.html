Configurações

Perfil do professor
Inteligência
Crie em console.anthropic.com → API Keys. A chave fica salva só neste navegador e é enviada apenas para api.anthropic.com.
A conferência usa a busca na web da API (Planalto, Senado, Câmara, STF, STJ). Ela precisa estar habilitada na organização no Console da Anthropic e tem custo por pesquisa.
Captação
O Claude sempre descarta conversas paralelas e ruídos. Se a transcrição parar de aparecer, desligue esta opção.
Ao clicar em Iniciar aula, a lousa abre automaticamente. Para voltar à tela de trabalho, use Sair na bandeja ou a tecla Esc.
Os blocos aparecem na lousa à medida que o Claude os escreve. Com 4 s, use o Haiku 5.5 para a resposta mais rápida, ou o Sonnet 5.5 para mais qualidade. Se uma organização ainda estiver em andamento, a fala nova entra logo na sequência.
